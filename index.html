Import ledger rows

Now auto-detects two kinds of file:
• Clean template (Customer Name, SI Date, Model, Engine No, Due Day, Terms, MA, Last payment, Outstanding Balance, Remaining Balance, Customer Status, Unit status, Mode of Payment, Date of Audit, Auditor Remarks, Last Audit Remarks, Amount Payment) — imported directly.
• Raw system export (Acct Type/Status Customer, Release/Rstr Date, Model, Engine No, Due, Term, MA, Beg, ...) — divider rows like "BNEW - ADV" are used as the Customer Status for the customers listed below them. Fields not present in the raw file are left blank.
The file's own name that you upload is used as the Branch for every customer in that file (e.g. "Cabuyao.xlsx" → Branch: "Cabuyao"), no matter how many tabs the workbook contains. Unless the file already has its own "Branch" column — then that's used instead.
You can now select multiple files at once (e.g. Cabuyao.xlsx, Malolos.xlsx, etc.) — they'll all be imported one by one, each using its own filename as its Branch.

Update Last Audit Remarks

Upload the new audit file (for example: a sheet with Customer Name and Last Audit Remarks columns). Only the "Last Audit Remarks" column is used — every other column in this file is ignored. Each row is matched to an existing customer using Customer Name (and Engine No if available, for a more accurate match), and only their "Last Audit Remarks" is replaced — the rest of the customer's data stays unchanged.
If a customer in the file has no matching record on the dashboard, they'll be added to the "unmatched" list after importing.

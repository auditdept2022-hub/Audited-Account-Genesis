Import ledger rows

Auto-detect na ngayon ang dalawang klase ng file:
• Clean template (Customer Name, SI Date, Model, Engine No, Due Day, Terms, MA, Last payment, Outstanding Balance, Remaining Balance, Customer Status, Unit status, Mode of Payment, Date of Audit, Auditor Remarks, Last Audit Remarks, Amount Payment) — direktang import.
• Raw system export (Acct Type/Status Customer, Release/Rstr Date, Model, Engine No, Due, Term, MA, Beg, ...) — ang mga divider row tulad ng "BNEW - ADV" ay ginagamit bilang Customer Status ng mga susunod na customer sa ilalim nito. Ang mga field na wala sa raw file ay iiwanang blangko.
Ang pangalan mismo ng file na ini-upload mo ang gagamitin bilang Branch ng lahat ng customer sa file na iyon (hal. "Cabuyao.xlsx" → Branch: "Cabuyao"), kahit ilang tabs pa ang laman ng workbook. Maliban na lang kung may sarili nang "Branch" column ang file — dun na kukunin.
Pwede ka nang pumili ng maraming file nang sabay-sabay (hal. Cabuyao.xlsx, Malolos.xlsx, atbp.) — iimport lahat isa-isa, at ang bawat isa ay gagamit ng sarili niyang filename bilang Branch.

Update Last Audit Remarks

I-upload ang file ng bagong audit (halimbawa: ang sheet na may Customer Name at Last Audit Remarks columns). Ang "Last Audit Remarks" column lang ang kukunin — lahat ng ibang columns sa file na ito ay balewalain. Ang bawat row ay itutugma sa existing na customer gamit ang Customer Name (at Engine No kung available, para sa mas tumpak na tugma), at papalitan lang ang "Last Audit Remarks" niya — ang ibang datos ng customer ay hindi magbabago.
Kung may customer sa file na wala pang record sa dashboard, ilalagay ito sa listahan ng "hindi natugma" pagkatapos mag-import.
No file chosen
Pwede ring i-paste ang rows sa ibaba (dapat may header row na may "Customer Name" at "Last Audit Remarks").
